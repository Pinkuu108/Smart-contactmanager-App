Smart Contact Manager

A secure, scalable and modern Spring Boot web application for managing contacts efficiently.

Project Overview

Smart Contact Manager is a full-stack web application built with Java and Spring Boot to securely store, manage and organize personal contacts with authentication and role-based access control.

Purpose of the Project

The project builds real-world experience in Java full-stack development by implementing authentication, database relationships, file uploads and responsive UI using industry-standard frameworks.

Technologies & Skills Used
  • Java: Core Java, OOP concepts
  • Spring Boot: MVC architecture
  • Spring Security: authentication & authorization
  • Spring Data JPA & Hibernate
  • Thymeleaf template engine
  • MySQL database
  • HTML, CSS, Bootstrap, JavaScript
Key Features
  • User registration and login
  • Secure authentication using Spring Security
  • Create, view, update and delete contacts
  • Upload contact profile images
  • Search contacts functionality
  • Responsive dashboard UI
Why Smart Contact Manager?

This project demonstrates the ability to design and develop a complete Java-based web application following MVC principles, security best practices and clean UI patterns similar to production systems.

Future Scope
  • Enhanced user profile management
  • Advanced search with pagination
  • REST API integration
  • Email and phone validation
  • Cloud deployment and monitoring
